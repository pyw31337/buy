# 렛츠바이 (Let's Buy)

> 인수인계: [HANDOFF.md](HANDOFF.md)


두 번 이상 산 물건을 찾아 구매 주기와 시즌을 읽고, "다시 살 때"와 "지금 가격이 괜찮은지"를 알려주는 개인용 구매 비서입니다.

- 웹: https://pyw31337.github.io/buy/ (데모 데이터로 바로 체험 가능)
- 모든 구매·가격 데이터는 **내 브라우저 안에만** 저장됩니다. 서버도, API 키도 필요 없습니다.

## 구성
| 폴더 | 역할 |
| --- | --- |
| `docs/` | 웹 화면 (GitHub Pages). 추천 · 재구매 품목 · 데이터 가져오기 |
| `extension/` | 크롬 확장. 로그인된 네이버 메일에서 주문메일 수집, 하루 1회 다나와 최저가 기록 |

## 확장 설치 (개발자 모드)
1. 이 저장소를 ZIP으로 내려받아 압축을 풉니다 (Code → Download ZIP).
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 "개발자 모드" 켜기.
3. "압축해제된 확장 프로그램을 로드합니다" → `extension` 폴더 선택.
4. 네이버 메일에 로그인한 탭에서 확장 아이콘 → "주문메일 자동 수집".
5. "렛츠바이 열기"를 누르면 웹 화면이 확장 데이터를 자동으로 받아옵니다.

## 한계 (솔직하게)
- 네이버 메일 자동 수집은 네이버 웹메일의 비공개 내부 주소를 사용합니다. 네이버가 바꾸면 막힐 수 있고, 그땐 메일을 열고 "지금 열린 메일 담기"를 쓰면 됩니다.
- 네이버 쇼핑 검색 API는 2026-07-31 종료되어 쓰지 않습니다. 가격은 확장이 사용자 브라우저에서 다나와 검색결과 최저가를 하루 한 번 기록해 쌓습니다. 과거 2년 가격은 다나와·폴센트 링크로 확인합니다.
