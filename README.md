# 렛츠바이 (Let's Buy)

> 인수인계: [HANDOFF.md](HANDOFF.md)


두 번 이상 산 물건을 찾아 구매 주기와 시즌을 읽고, "다시 살 때"와 "지금 가격이 괜찮은지"를 알려주는 개인용 구매 비서입니다.

- 웹: https://pyw31337.github.io/buy/ (데모 데이터로 바로 체험 가능)
- 모든 구매·가격 데이터는 **내 브라우저 안에만** 저장됩니다. 서버도, API 키도 필요 없습니다. 사진 공유 캐시만 사용자가 따로 켤 수 있습니다.

## 구성
| 폴더 | 역할 |
| --- | --- |
| `docs/` | 웹 화면 (GitHub Pages). 추천 · 재구매 품목 · 데이터 가져오기 |
| `extension/` | 크롬 확장. 로그인된 네이버 메일에서 주문메일 수집, 하루 1회 다나와 최저가 기록 |

## v0.18.1 — 검토 가능한 분석으로 보강

- 구매 기록에 **검토** 필터를 추가해 자동 추정한 실물 품목만 모아서 확인할 수 있다.
- “옷장용 제습제”처럼 사용 장소가 포함된 소모품을 가구로 오인하지 않도록 분류 규칙을 보완했다.
- 확인한 분류는 이후 재구매·가격·사진 정책에도 동일하게 적용된다.

## v0.18.0 — 소비 원장과 재구매 판단을 분리
- 원본 주문은 그대로 보존하면서, 포인트·쿠폰·배송비·상품권·충전금은 **정산·결제 흐름**으로 분리합니다. 이 항목은 지출 합계·사진·가격·재구매 추천을 오염시키지 않습니다.
- 디지털 콘텐츠·구독·예약 서비스는 소비 분석에는 남기되 실물 사진·최저가·소모품 재구매 대상에서는 제외합니다. 문화·취미, 홈·인테리어, 가구, 문구·완구를 독립 분류합니다.
- 사용자가 분류를 고치면 그 기준을 확장에도 동기화해 이후 사진·가격 수집과 알림에도 반영합니다. 대시보드에는 분석 신뢰도와 검토 대상을 표시합니다.
- 홈·살 때·내 소비·구매 기록의 위계를 다시 설계해, “다음 행동”과 원본 기록을 혼동하지 않게 했습니다.

## v0.17.1 — 멈춘 사진 검색을 감추지 않고 재개
- 확장 업데이트·브라우저 재시작 뒤에도 남아 있는 사진 검색 대기열을 자동으로 다시 등록합니다.
- 90초 동안 진행 기록이 갱신되지 않으면 “다음 묶음 자동 진행”이라고 표시하지 않고, **중단된 검색 이어서** 버튼을 보여 줍니다. 기존 대기열을 처음부터 다시 만들지 않고 멈춘 지점부터 잇습니다.

## v0.17.0 — 전체 실제 주문 사진 수집
- 쿠팡은 `mc.coupang.com`의 차단되기 쉬운 SSR 주소 대신, 로그인된 일반 **마이쿠팡 주문목록**을 엽니다.
- 네이버페이·쿠팡 주문목록의 연도와 페이지를 순차적으로 읽고, 페이지 번호가 없는 목록은 아래로 내려가며 실제 주문 카드를 수집합니다. 진행·누적 사진 수를 화면에 표시하고 한 번에 최대 120개 화면까지만 읽습니다.
- 지원하지 않는 다른 쇼핑몰의 주문목록은 임의로 로그인·수집하지 않습니다. 현재는 메일 수집과 네이버페이·쿠팡의 실제 주문 화면 수집을 분리해 제공합니다.

## v0.16.1 — 주문 행이 없어도 실제 사진 대조
- 네이버페이·쿠팡이 주문 날짜·가격의 텍스트 구조를 바꿔 주문 행을 0건으로 읽어도, 현재 열린 실제 주문 카드의 상품명·사진을 기존 메일 구매명과 직접 대조합니다.
- 광고·로고·여러 카드에 반복되는 기본 이미지는 제외하고, 이름 토큰이 충분히 일치할 때만 사진을 붙입니다. 한 쇼핑몰 실패가 다른 쇼핑몰의 성공 결과를 덮어쓰지 않습니다.

## v0.16.0 — 실제 주문 사진 우선
- `실제 주문 사진`을 누르면 로그인된 네이버페이·쿠팡 주문내역을 열고, 화면에 표시된 **실제 구매 상품 이미지와 링크**를 주문명에 대조해 반영합니다.
- 외부 상품명 검색은 `검색으로 보강`으로 분리했습니다. 실제 주문 사진을 먼저 쓰므로 다른 상품 사진을 잘못 붙일 가능성을 낮춥니다.
- 주문목록이 SPA로 늦게 그려지는 경우에도 최대 5회 기다린 뒤 읽고, 수집 결과를 화면에 표시합니다.

## v0.15.2 — 사진 검색 재시도·진단
- 한 쇼핑몰이 막혀도 나머지 검색원을 계속 시도합니다. 단순히 사진이 없는 검색 결과는 해당 쇼핑몰 차단으로 세지 않습니다.
- 완료 뒤에도 검색 횟수와 새로 찾은 사진 수를 표시하고, 확장 진단에는 검색원별 성공·차단·네트워크·이미지 변환 결과를 남깁니다.

## v0.15.1 — 사진 채우기 복구
- 사진 검색 요청마다 시간 제한을 두어 첫 결과가 멈춰도 `0/N`에서 무한 대기하지 않습니다.
- 한 번에 12개씩, 최대 3개 동시 처리 후 자동으로 다음 묶음을 이어 갑니다. 브라우저가 중간에 쉬어도 진행 상황과 대기열을 보관합니다.
- 오류가 나면 진행 표시가 멈춘 채 남지 않고 이유와 `다시 시도` 버튼을 표시합니다.
- 메일에 이미 포함된 사진은 다시 검색하지 않습니다.

## v0.15.0 — 신뢰성·안전성 정비
- 홈에서 확장 연결·저장소·최근 가격 수집을 한눈에 확인하는 **자가진단**을 제공합니다.
- 메일 수집의 실제 진행률을 웹 화면에 표시하고, 중단하면 읽은 범위까지만 저장합니다.
- 초기화·구글 드라이브 덮어쓰기 전 최근 5개 자동 백업을 남기고 복원할 수 있습니다.
- 검색 결과의 상품명 유사도를 기록합니다. 낮은 유사도 상품에는 “지금 사세요” 대신 확인 안내를 표시합니다.
- 사진 검색은 사용자가 `사진 채우기`를 눌렀을 때만 실행합니다. 제품명 해시·사진 공유 캐시는 기본으로 꺼져 있습니다.
- 선물·한꺼번 구매처럼 추천이 불필요한 품목은 상세에서 재구매 추천을 제외할 수 있습니다.

## 확장 설치 (개발자 모드)
1. **웹사이트의 확장 다운로드 ZIP을 받았다면:** 압축을 풀어 `manifest.json`이 바로 보이는 폴더를 준비합니다. **이 저장소를 Code → Download ZIP으로 받았다면:** 압축을 푼 뒤 `extension` 폴더를 준비합니다.
2. 크롬 주소창에 `chrome://extensions` 입력 → 오른쪽 위 "개발자 모드" 켜기.
3. "압축해제된 확장 프로그램을 로드합니다" → 앞 단계에서 준비한, `manifest.json`이 있는 폴더 선택.
4. 네이버 메일에 로그인한 탭에서 확장 아이콘 → "주문메일 자동 수집".
5. "렛츠바이 열기"를 누르면 웹 화면이 확장 데이터를 자동으로 받아옵니다.
6. 홈의 **연결 상태 자가진단**에서 `페이지 연결 · 확장 준비 · 데이터 저장소`가 모두 확인되는지 봅니다.

## v0.18.3 — 수집 안전장치 및 분석 품질 대폭 강화
- **쿠팡 주문 순회 안전화:** 페이지네이션 전용 컨테이너 내의 이동 버튼만 탐색하고 캐러셀·배너의 오클릭을 차단했습니다. 301 리다이렉트나 CloudFront 백지 화면, 보안 차단 감지 시 작업을 안전하게 종료하고 안내합니다.
- **쇼핑 도우미 위젯 격리:** 상품 상세 페이지에서만 실행되도록 URL 검증을 강화하고, 에러 제목(301, Moved Permanently 등)을 상품명으로 오인하는 문제를 완전히 수정했습니다. 수집 플로팅 버튼과의 UI 겹침도 해소했습니다.
- **분석 및 정제 품질 고도화:** 쿠팡 로켓배송·새벽배송·로켓와우 등 배송 접두사가 포함된 상품명을 정확하게 정제하고 품목으로 인정합니다. 키친타월, 두유, 유산균, 배변패드 등 다빈도 생활 소모품 분류 사전을 대폭 보강하고, 최근 구매 간격에 가중치를 두어 소비 주기를 정밀 예측합니다.
- **온보딩 퀵 스타트 가이드:** 사이트 자가진단 패널에 네이버 메일·Gmail·네이버페이 원클릭 바로가기를 배치하여, 신규 사용자가 헤매지 않고 손쉽게 2개년 주문을 수집할 수 있도록 안내를 강화했습니다.
